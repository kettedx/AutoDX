# 🏎️ Sobre o projeto

O **AutoDX** é uma garagem virtual automotiva criada para aprendizado e evolução no desenvolvimento front-end.

Inspirado em catálogos premium e garages modernas, o projeto busca entregar uma experiência visual imersiva com foco em design, organização e estilo automotivo.
